# Client

The React and TypeScript frontend for AI SEO Tracker lives in this directory.

For the complete project overview, setup instructions, environment variables, API documentation, and scripts, see the [root README](../README.md).

## Client commands

Run these commands from `client/`:

| Command | Description |
| --- | --- |
| `npm install` | Install client dependencies. |
| `npm run dev` | Start the Vite development server. |
| `npm run build` | Type-check and create a production build. |
| `npm run preview` | Preview the production build locally. |
| `npm run lint` | Run ESLint. |
